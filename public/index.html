BYTE BACK 내 자료실 브라우저에서 사용 중

이 웹사이트는 설치형 웹앱으로 추가할 수 있습니다. 별도 접속 프로그램을 내려받거나 설치하지 않습니다.

앱 설치 표시는 기기 승인과 별개입니다. 설치했다고 보호 자료 접근 권한이 생기지 않습니다.

오프라인에서는 연결 안내 화면만 표시합니다. 로그인 정보, 기기 승인 응답, 메모 내용과 API 응답은 오프라인 캐시에 저장하지 않습니다.

기기 승인

서버 확인 상태 확인 전

승인 요청은 이 기기의 패스키 공개키를 서버에 승인 대기로 등록할 뿐입니다. 승인 버튼을 눌렀다는 사실만으로 자료 접근 권한을 주지 않습니다.

기기 개인키는 브라우저 저장소에 넣지 않고 기기의 패스키 인증기에 남깁니다. 서버가 승인 상태와 패스키 서명을 모두 확인한 뒤에만 짧은 기기 세션을 발급합니다.

가상 메모와 로그인 요청은 서버 함수를 통해 처리합니다.
