# ARGUS-X 0.2.11 | 처음 보는 사람을 위한 1장 실행 안내
> **Windows · 일반 사용자 권한 · 프로젝트 폴더에서 직접 실행 · 설치 프로그램/포장 없음**  
> 이 문서는 이미 전달받은 **ARGUS-X 프로젝트 전체 폴더**가 있는 사람을 위한 안내입니다. 남의 PC에서 `127.0.0.1`은 **그 사람 PC**를 뜻하며, 원격으로 앱에 접속하는 주소가 아닙니다.

## 1. 시작 전 확인
- Windows PC, PowerShell, **Node.js 24.19.0 권장**(실행 도구는 Node.js **22~24** 지원). Node.js가 없을 때에만 [공식 사이트](https://nodejs.org/)에서 설치하고 PowerShell을 새로 엽니다. **앱 설치 파일은 만들거나 실행하지 않습니다.**
- 전달받은 프로젝트에서 `on-client\package.json`, `on-client\src\server.mjs`, `on-client\tools\start-alekov.ps1` 파일이 있는지 확인합니다. **기존 폴더, 이전 제출물은 삭제·이동·덮어쓰기 금지.**
- 예시로 작업자 PC의 폴더는 `C:\github\ARGUS-X-22-repro\on-client`입니다. **다른 사람은 실제 전달받은 폴더**를 사용하세요.

## 2. PowerShell에서 순서대로 실행
파일 탐색기에서 **`on-client` 폴더**를 연 뒤 주소 표시줄에 `powershell` → Enter를 누르세요.

```powershell
node --version
npm.cmd run check
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

- `node --version`: Node.js 버전 확인. **권장: v24.19.0**. `npm.cmd run check`: **학생 JS 문법만 검사**, 앱 전체 기능 테스트는 아닙니다.
- 마지막 명령에서 **“케셰브가 켜졌습니다. 브라우저에서 http://127.0.0.1:5189/ 을 여세요.”**가 나오면 로컬 서버 시작 성공입니다. “케셰브”는 기존 실행 스크립트의 안내 이름으로, ARGUS-X 실행 오류가 아닙니다.
- **서버 창을 닫지 말고**, 같은 PC의 브라우저에서 **http://127.0.0.1:5189/** 를 엽니다. 서버 응답 성공은 **SDP/AI 연결 성공이 아닙니다.** 종료할 때만 실행 창에서 **Ctrl+C**를 누릅니다.

## 3. 첫 화면에서 직접 확인 (실측값을 임의로 만들지 않기)
1. **보호 현황**의 1일차 핵심 동선 3개: **기록 보기 → 내 PC 상태 → 위험 알림**. 기본 실행은 원천 SDP가 **연결 없음**일 수 있으며, 기록 실패는 “위험 없음”을 뜻하지 않습니다.
2. **내 PC 상태(2일차)**: `PC 상태 다시 조회` → **CPU(%)·메모리(GiB)·디스크 여유(GiB)·조회 상태** 카드 4개, 측정 시각·아래 추이/기록 확인. 같은 버튼을 새로고침 없이 2회 눌러 직전 성공값과 비교합니다.
3. **네트워크·보안 관제(3일차)**: `네트워크·보안 다시 조회` → 네트워크·방화벽·Windows 경고/오류·SDP 상태 **4개 카드**, 아래 추이/기록 확인. 방화벽은 **읽기만 함**. System/Application 경고·오류 건수는 **침해/공격 탐지 건수가 아닙니다.**
4. **학생 상태·알림(4일차)**: 카드 4개와 `기록 다시 조회` 버튼 → **조회 중 “새로 읽는 중…”**, 완료 뒤 **실제 기록 또는 “확인 불가”·오류 코드·다음 행동** 확인. **Tab**으로 버튼에 이동하고 **Enter**로 실행할 수 있어야 합니다.
5. **실제/예제 구별**: `실측`·조회 시각이 있는 수치만 실제 측정값입니다. `demo`는 예제, `조회 전/확인 불가`는 미측정·실패입니다. PC 조회 성공과 SDP 상태는 별개입니다.

## 4. 막혔을 때 (설정 변경·강제 권한 상승 금지)
| 막힌 화면/오류 | 확인할 것과 다음 행동 |
|---|---|
| `node` 명령 없음 / 지원 버전 아님 | Node.js **24.19.0** 설치/버전 확인 → **새 PowerShell**에서 2번부터 다시 실행 |
| `앱 폴더가 아닙니다` / 실행 파일 없음 | 현재 폴더가 전달받은 **`on-client`**인지 확인; 파일을 지우거나 재설치하지 않기 |
| `포트 5189 를 다른 프로그램이 쓰고 있습니다` | 기존 앱을 중복 실행했는지 확인. 다른 프로그램을 강제 종료하지 말고 `-Port 5190`으로 실행하면 **http://127.0.0.1:5190/** 로 접속 |
| `ENGINE_NOT_CONNECTED` / `SDP 미연결` | **기존 SDP 서버·에이전트 연결 어댑터** 미연결 상태. PC 자체 측정 실패와 구분. 관리자의 연결 안내 없이 인증정보·정책을 임의 수정하지 않기 |
| `확인 불가` / `TIMEOUT` / `ACCESS_DENIED` | **실패 항목과 이유**를 기록. 로컬 서버·일반 사용자 조회 권한을 확인하고 해당 **다시 조회**를 누르기. 관리자 권한이나 방화벽 설정은 변경하지 않기 |

## 5. 다른 사람이 안내만 보고 따라 한 결과 (작성 전에는 성공으로 표시 금지)
- 테스트한 사람/PC(개인정보 제외): **미기록**
- Node.js 버전 / 사용한 프로젝트 폴더: **미기록**
- 마지막으로 성공한 단계: **미기록**
- **실제로 막힌 단계와 오류 원문**: **미제공** (위 오류 표는 *대처 예시*이며 다른 사람의 실측 결과가 아님)
- 원인 분류(안내/코드/환경/확인 불가): **확인 전**
- 필요한 최소 수정과 수정 파일: **확인 전**
- 안내만 보고 다시 실행한 결과: **미검증**

**보존·보안:** `ARGUS-X-22-repro` 작업 폴더, 원본 `aleph-defense-starter`, 기존 제출 커밋을 지우거나 옮기지 않습니다. 비밀키·토큰·IP/DNS 상세 정보를 캡처나 기록에 넣지 않습니다. 설치형 `setup.exe` 제작·배포, 포장 명령, 공격 실습, 방화벽·보안 설정 변경은 **수행하지 않습니다**.
